# Spikes (Phase 0)

Bauen: `./build.sh` → Tools landen in `bin/`.

| Tool | Zweck | Berechtigung |
|---|---|---|
| `bin/ax-spike dump` | AX-Baum des Finder-Kopierfensters ausgeben (während einer Kopie!) | Bedienungshilfen für Terminal |
| `bin/ax-spike watch` | Fortschritt alle 0,5 s auslesen, Geschwindigkeit pro Vorgang + Summe | Bedienungshilfen für Terminal |
| `bin/progress-spike <Zielordner>` | Prüft, ob der Finder `NSProgress` für Kopien veröffentlicht | keine |
| `bin/io-spike` | Bytes/s pro Datenträger und Netzwerk-Interface | keine |
